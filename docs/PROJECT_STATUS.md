## 2026-11-26初步实机测试

设备为29DoF G1，策略为上述15k模型。VR输入、模式切换和低层命令链路已运行。
以下为日志离线分析，尚未修复；不能称为稳定实机遥操通过：

- PLANNER idle仍产生变化的参考，不是固定姿态。观察到轻微抖动与声音；根因及增益贡献尚未分离。
- POSE与PLANNER双向切换时目标角不连续：踝目标单周期曾跳变26.4度，上肢个别跳变76.6度。
  保留历史与航向不能保证action连续，模式过渡仍待修复。
- 起身曾触发reference tilt error进入DAMP；相对倾斜阈值约20.1度，随后Kp归零。
  输入根姿态连续侧倾的来源（人体动作或解算偏差）尚未确定；不是该次日志中的VR断流。
- POSE不显式消费人体全局平移；局部姿态跟踪不保证人体位移跟随。
- --stationary-lower-body屏蔽planner行走命令，包括VR_3PT摇杆；它没有冻结所有关节，也不限制POSE腿部动作。
- 实时POSE单帧补齐9帧，与训练真实未来窗口不同，影响待验证。
- VR_3PT两段共1614帧：实测关节角FK相对VR目标的左/右手平均位置误差10.75/10.44厘米，
  平均朝向误差17.07/26.20度。使用官方G1模型、训练同款偏移和骨盆坐标系，
  这是运动学估计而非外部定位真值。排除切换首秒后仍存在误差。
- PD目标角的FK不是要求瞬间达到的参考手姿，不能把其与实测FK之差直接等同为电机故障。
- IMU外参采用参考模型，尚无本机标定结果。DAMP不能保证无支撑站立。
